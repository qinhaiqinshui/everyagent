# workflow 插件 · 人工验证清单（交付手测）

汇总自各前端面板源码尾注释的「人工验证清单」（编辑器/侧边栏/运行对话框/实例页/运行日志页），
补入后端与 hidden 工具侧的人工观察点。自动化验证已覆盖的部分（单测/typecheck/构建链）不在本表，
本表只列**需要真人开浏览器对着 worker 跑一遍**的项。

## 0. 前置

1. 起一个 hub（默认端口 8100）与本仓库 worker（cwd=仓库根，内置插件按 `user.dir` 扫描），
   worker 日志确认「插件已激活： id=workflow」且无「内置插件未构建」WARN（先跑
   `python scripts/build-plugins.py`）。
2. web dev server（`cd every-agent-web && npm run dev`）连上 worker，注册表里准备两个工作区
   便于验证隔离。
3. 至少一个可用模型配置（AI 节点/supervisor 需要真实模型；纯命令节点工作流不需要）。

## 1. 定义编辑器（画布 + 属性面板，步骤 8）

1. 侧边栏「工作流」组头「管理」→ 管理页「新建」→ 打开空白定义编辑器 → 画布出现「开始」节点，右下角 dirty ●。
   **右侧属性面板默认不占位**（无选中=画布占满；与实例详情面板同款隐藏规则）。
2. palette 添加命令节点 + AI 节点（落画布中心附近，自动选中 → 属性面板出现）。
3. 拖动节点改位置；从「开始」右侧锚点拖到命令节点建立边；再连到 AI 节点。
4. 选中边 → 条件类型切 onSuccess；选中命令节点 → 填 command/timeoutMs/maxRuns；
   选中 AI 节点 → 新建 agent「writer」并选用、填 input 模板、选模型覆盖。
   **点画布空白处属性面板不隐藏**（保留最近选中）；面板顶部 × 关闭（清选、面板卸载）。
5. 左栏展开「运行变量」加一个 required 变量、「出错策略」确认默认 supervisor + 选督导模型、
   「Agents 总表」确认 writer 已列入。
6. 保存 → toast「工作流已创建：wf_…」，dirty ● 消失，标题处显示定义 id。
7. 关闭标签页 → 重新从管理页打开同一定义 → 节点位置/连线/条件/命令/
   agent/input/变量/onError/supervisor/agents 全部还原（def.get 原样回读）。
8. 反向校验：删掉 command 内容保存 → 出现红色逐项错误列表（后端校验器返回）。

## 2. 侧边栏（只展示运行实例，推送驱动）

1. 打开侧边栏「工作流」：注册表里每个工作区一张分组卡片**同时并陈**（含空工作区，
   显示「暂无运行实例——点右上「管理」新建或运行工作流。」），**无**顶部下拉/工具条，
   **无定义子区**（定义只在管理标签页展示）；组序=注册表顺序。
2. 组头：仅点击箭头折叠/展开（点组名不折叠）；右侧=▶ / 管理 / ⋯（⋯ 内=「刷新」+
   「批量删除」，后者红色危险项）；组内实例行直接平铺（无子区头、无折叠、无计数）。
3. 组头「▶」（无定义时禁用）→ 工作区级运行窗：顶部下拉列出本工作区全部定义，默认选中
   最近一次实例的定义（无实例/定义已删 → 首个）；切换定义 → 变量表单重挂载重置；填齐
   变量点「开始运行」→ 弹窗关闭并打开实例运行页（标题=`定义名 · 实例id`）；
   取消/Esc → 无实例创建。
4. 运行中实例：状态药丸蓝色「运行中」；⋯ 菜单=「复制工作流路径」/「取消实例」/「删除」；
   点行打开实例页，tab.data.instanceId 正确；「取消」→ confirm → 状态转已取消
   （琥珀「已取消」）。
4b. **复制工作流路径**：hover 实例行 → 打开 ⋯ 菜单（此刻预取 instance.dataDir）→ 点
   「复制工作流路径」→ toast「已复制工作流路径」，粘贴得到 worker 宿主上的
   `…/workspaces/<wsId>/workflows/instances/<wiId>/` 绝对路径；**局域网 http（非安全
   上下文）下同样成功**（预取 + 同步写保手势）；实例已被他端删除时点复制 → toast 报
   「工作流实例不存在…」；极少数环境写不进剪贴板 → 弹手动复制模态（文本域已全选，
   Ctrl+C / ⌘C 或「重试复制」按钮可用，后者几乎必然成功）。
5. **推送（重点）**：另一端运行工作流 / 任务 AI 调 workflow_create / 实例 running →
   waiting-user → done 翻转 → 侧栏在 ~150ms 内自动更新；取消实例 → 状态药丸转琥珀；
   删除 → 条目消失。全程不点刷新。
6. 删除终态实例 → 目录清除、列表消失。
6b. **批量删除**（宿主任务侧边栏同款交互，作用域=单工作区组）：组头 ⋯ →「批量删除」→
    组头变「☐ 全选 / 删除 / 取消」（▶/管理/⋯ 让位），组内实例行出勾选行：终态实例
    （已完成/失败/已取消）可勾「选择删除」，运行中/等待用户实例禁勾并显示
    「进行中不可删除」，行尾保留「打开」按钮，行 ⋯ 菜单隐藏、点行不再打开实例；
    勾选若干 →「删除 (n)」→ 确认弹窗（不可恢复）→ 串行删除、toast「已删除 N 个
    实例」、自动退出批删并回到常规组头；「取消」直接退出不动数据；组内实例全部
    活跃时菜单项禁用；删除途中 worker 报错（如实例恰好被他端删除）→ 首错即停、
    toast 报「已删 X 个」、剩余保持勾选可重试；批删中他端删除选中实例或实例转
    活跃 → 勾选自动清理；批删组的工作区被注销 → 自动退出批删模式；「工作区缺失」
    尾组同样支持批量删除（清理孤儿数据）。
7. 归属工作区未注册的实例收进尾组「工作区缺失」（只读，行内 chip 显示
   workspaceId）；注册表变化后尾组条目回到对应工作区组。
8. 行内时间：7 天内相对时间，点击切换绝对/相对，title 显示完整绝对时间。

## 2.5 管理标签页（workflow-manage · 每工作区一个定义管理页）

1. 侧边栏组头「管理」→ 打开本工作区的管理标签页（标题「管理工作流」+ 工作区名/id 副标题）；
   同一工作区重复点击聚焦同一标签（不新开）；不同工作区各自成标签。
2. 顶栏动作组：「新建」（绿）→ 打开空白定义编辑器；「删除」（红，新建右边）→ 进入
   批量删除；「导入」→ 二选一菜单（**导入文件**〔.workflow.json 文件选择器〕/
   **粘贴 JSON**〔弹窗粘贴〕，Esc/点外部关闭）；「刷新」→ 全量重拉。无定义或
   动作进行中时「删除」禁用。
3. 定义行：名称+描述 / 等宽 id · 节点数 · 更新时间；行点击 → 编辑器打开同一定义；
   hover 边框高亮；行尾=**常显「▶ 运行」绿色直点按钮**（hover 同步浮现）⋯ 菜单=
   编辑 / 查看 JSON / 导出 JSON / 删除。
4. **行尾「▶ 运行」**：点击直达运行窗（不触发行点击/不开编辑器）；该定义「查看
   JSON / 导出」进行中时按钮同步禁用；批删模式下按钮随行尾操作区一起隐藏。
5. 「查看 JSON」→ 对话框展示完整 definition JSON（可滚动）；「复制」→ toast
   「已复制到剪贴板」，**非安全上下文（局域网 http）下同样成功**（异步 Clipboard
   API → execCommand 同步兜底 → 手动复制降落伞三级收口，绝不静默失败/误报）。
6. 「导出 JSON」→ 浏览器下载 `<名称>.workflow.json`（内容=definition.json 原样）；
   「导入 → 导入文件」选回该文件 → toast「已导入为 wf_…」（id 重赋）；导入残缺
   JSON（删掉 name）→ 顶部红色逐项回显；导入非法 JSON → 「文件不是合法 JSON：…」。
6a. **粘贴导入**：「导入 → 粘贴 JSON」→ 弹窗 textarea（Ctrl+Enter 直达导入）；
    空文本点导入 → 弹窗内红字「请先粘贴 JSON 内容」；粘贴残缺/非法 JSON →
    逐项错误回显在弹窗内（改完文本可直接重试，不必关窗）；成功 → 关窗 + toast
    「已导入为 wf_…」+ 列表 ~150ms 自动刷新；导入中按钮 loading 防重复提交。
7. 「删除」→ 宿主模态 confirm → 确认后行消失；实例保留（持快照）。
7b. **批量删除定义**（侧栏实例批删同款交互）：顶栏「删除」→ 动作组换「☐ 全选 /
    删除 / 取消」（新建/导入/刷新让位），定义行首出勾选框、点行=切勾选（⋯ 菜单
    与行尾「▶ 运行」一起隐藏、不再打开编辑器）；全选/反选联动「删除 (n)」计数
    （0 个禁用）→ 确认弹窗
    （提示**仅删定义、已运行/历史实例不受影响**）→ 串行 def.delete、toast
    「已删除 N 个定义」、自动退出批删模式；删除途中报错（定义恰被他端删除）→
    首错即停、toast 报「已删 X 个」、剩余保持勾选可重试；批删中他端删除选中定义
    → 勾选自动清理；定义清空 → 自动退出；「取消」无副作用退出；删除后侧栏实例
    保留（持快照，运行页可继续查看）。
8. **推送**：编辑器保存定义 / AI 调 workflow_create / 另一端导入 → 本页 ~150ms 内自动更新，
   无需手动刷新。
9. **移动端（≤768px）**：顶栏动作组换行全宽、按钮等分放大（批删模式=全选+删除+取消
   同样换行放大）；行内名称+⋯ 首行、meta 次行堆叠；行尾「▶ 运行」自然宽常显
   （触控目标 ≥30px）；批删勾选框占行首列；⋯ 菜单常显可点；粘贴导入弹窗
   textarea 16px 防 iOS 聚焦自动放大、宽度收窄至 92vw 不溢出。

## 3. 运行对话框（步骤 9）

1. 管理页定义行行尾「▶ 运行」（或侧栏组头 ▶ 选定义）→ 对话框列出全部变量声明；
   required 标 *、label/description/defaultValue（placeholder「默认：…」）正确显示。
2. required 留空点「开始运行」→ 黄字「缺少必填变量：…」，不发 RPC。
3. 填齐后运行 → 对话框关闭，实例页标签打开（地址栏 tab.data.instanceId 正确），
   侧边栏实例列表出现 running 实例。
4. 模型配置故意填错运行 → 后端 BAD_PARAMS 的 message 完整展示在对话框红框内。
5. Esc / 点遮罩 / 取消 → 对话框关闭，无实例创建。

## 4. 实例运行页（步骤 10）

1. 侧边栏实例列表点击实例（或运行对话框启动后自动打开）：实例页加载出画布
   （位置与定义一致）、顶栏状态色点/定义名/变量摘要/时长正确。
2. 运行中实例：节点随事件实时着色（start→绿、命令/AI 蓝→绿、失败红、跳过灰、
   等待决策黄），运行中节点描边呼吸动画；已激活出边转绿（skip 决策节点全部出边绿）。
3. 节点副标题：无输出时显示「运行中…/失败原因/状态」；产出后显示最新输出首行摘要。
4. 点击节点：右侧详情面板**按需出现**（无选中时不占位、画布占满），显示节点信息、输入三视图（模板/渲染后胶囊富文本/AI 所见）、
   输出全量（命令 stdout/stderr 分块+exit 徽标；AI text 全文）、错误红块、agent
   会话轮与 tokens 用量、激活出边 chips、历次 run 记录列表（点击切换查看对应全量）；
   **点画布空白处不隐藏详情**（保留最近选中，面板持续刷新运行数据）；关闭走面板
   顶部 × 按钮（桌面吸顶/移动端抽屉右上角）。
5. 点击边：显示 from/to/条件类型与激活状态；空白点按同样保留边详情，× 关闭。
6. askUser 策略实例：顶栏下出现琥珀决策横幅（question/context/节点与 runNo）；
   「重试/跳过/终止」直接提交，「换输入重试」展开 textarea（留空不可提交）；
   提交后横幅消失、实例回运行中、节点继续推进；后端拒绝（runNo 不匹配等）时红字回显。
7. 取消（运行中顶栏按钮）：confirm → 状态转已取消、事件流停止（顶栏无重连提示）；
   终态实例顶栏显示「删除实例」，删除后页面转「实例已删除」占位。
8. 断网/重启 worker：宿主全局重连提示弹出；恢复后事件流自动续流（游标不丢事件，
   订阅恢复触发拉取补洞），节点着色/顶栏状态继续推进。
9. 切「运行日志」视图：见 §5；两视图共享同一事件流，切换无重拉闪烁。
10. 终态历史实例回放：打开即全量投影（事件回放+nodeStates 补洞），进度与侧栏一致；
    顶栏无刷新按钮（meta/runs 由事件驱动防抖重拉，无手动入口）。
11. 推送链路：实例页打开期间 worker 侧 events.jsonl 每追加一条事件（可另开终端
    `tail -f` 观察），前端节点着色/运行日志在秒级内跟进——全程无手动刷新。

## 5. 运行日志页（步骤 10）

1. 实例页顶栏切「运行日志」：时间线从上到下=实例创建（含变量明细行）→ 各节点运行
   卡片 → 实例状态行；左侧圆点轨道按 tone 着色（绿=完成/琥珀=等待与取消/红=失败）。
2. 命令节点卡片：stdout/stderr 分块（等宽字体、可滚动）+ exit 徽标（0=绿，非 0=红）。
3. AI 节点卡片：输入为胶囊富文本（宿主 TokenRichText；缺席宿主下降级纯文本——
   含 @file 引用 token 的输入可见胶囊）；输出为最终回复全文 pre 块；agent 行显示
   会话轮增量与 tokens 用量。
4. 失败节点卡片：红色错误块；supervisor 介入后同卡片追加「督导介入链」行
   （介入 #n → retry/skip/... — reason），且时间线出现对应督导状态行。
5. 运行中实例：进行中节点先出现「运行中」闪烁徽标的合成卡片（输入预览来自
   node.started 事件）；节点收口落盘后点「重载」→ 合成卡片被真记录卡片取代
   （exit/输出全量）。不点重载也不重复（runNo 去重）。
6. 「重载」按钮：重拉 runLog（顶栏进度/右侧详情同步刷新）；事件行不受影响。
7. askUser 挂起：时间线出现「等待用户决策（节点 · run #n）」琥珀行（question/
   context 明细）；决策后出现「实例状态 → 运行中」行，节点继续产出卡片。
8. 取消实例：出现「实例已取消（操作者：user）」行；被中断节点无收口卡片
   （其合成卡片保持运行中态——与引擎「中断如实呈现」口径一致）。
9. 终态实例回放：整页历史完整（wf.created → … → wf.done/failed/cancelled 收尾）。

## 5a. 移动端适配（视口 ≤768px，桌面窄窗或手机/平板竖屏均可验证）

工具：devtools 设备模拟（触屏仿真）或真机访问 dev server；拖动窗口宽度跨 768px
可实时观察桌面/移动形态切换（useIsMobile 监听 matchMedia change）。

1. **画布触屏交互**（编辑器）：单指拖动节点改位置、从右锚点（扩大命中区）拖出连线
   落到目标节点，均不触发页面滚动；空白背景单指拖动=平移画布；tap 节点/边=选中，
   tap 空白=取消选中。桌面鼠标拖拽/连线行为不回归。
2. **Ctrl+拖拽平移画布**（编辑器与实例运行图通用）：按住 Ctrl 画布光标变手型（grab，
   拖动中 grabbing），按住拖动任意位置（含节点/锚点上）平移画布且不触发选中/节点
   拖拽/连线；松开 Ctrl 或窗口失焦后光标恢复、交互回归；无 Ctrl 时原行为不变。
2. **编辑器抽屉**：工具栏出现「组件/属性」按钮（桌面隐藏）；左抽屉=palette+变量/
   策略/agents，右抽屉=选中项属性面板（仅在选中节点/边后挂载）；点按节点/边或
   palette 添加节点 → 右抽屉自动滑入；点遮罩或 × 收起（× 同时清选卸载面板）；
   属性面板内「删除节点/边」按钮可用（触屏无 Delete 键）。
3. **实例页底部抽屉**：tap 节点/边 → 详情从底部滑出（× 收起，收起后再 tap 重开）；
   顶栏换行（变量摘要独占一行）；askUser 决策横幅按钮可点。
4. **侧边栏**：⋯ 行操作菜单与组头 ⋯ 菜单常显（不依赖 hover）且触控目标 ≥30px；
   组头折叠箭头可点按；批量删除模式的勾选行/「全选」可点按（触屏点行不误开实例页）。
5. **运行对话框**：92vw 内不溢出，必填校验/提交流程同桌面。
6. **运行日志页**：头部说明换行不遮挡按钮，卡片与 pre 块窄屏可读、可滚动。

## 6. 引擎行为（后端观察点）

1. **同 agent 名节点全局互斥**：构造「两并行分支同用 agent A」的定义，实例运行时
   两节点串行（先到先跑），`agents/A.jsonl` 会话线无交错；事件时间线可见先后。
2. **循环上限**：造一个 A→B→A 的环，跑到 maxRuns 上限后实例 failed，错误信息指明
   节点超限。
3. **命令节点超时**：`timeout: 3` + `ping -n 30 127.0.0.1`（Windows）→ 节点失败，
   exit/错误如实进 runs 记录。
4. **supervisor 督导**：命令节点故意失败 + onError=supervisor → 时间线出现督导介入链
   （retry/skip/fail/retryWithInput 之一 + reason），supervisor 会话线
   `agents/supervisor.jsonl` 连续介入累积上下文；介入达 3 次上限后 fail。
5. **askUser**：onError=askUser 的失败 → 实例 waiting-decision、§4.6 决策横幅可用；
   决策后节点按选择推进（换输入重试=新输入生效）。
6. **取消语义**：运行中取消 → 运行中节点停止、无收口卡片、实例已取消；磁盘 meta.json
   状态一致。
7. **重启中断**：实例运行中重启 worker → 激活扫描把非终态实例标 failed
   （「worker 重启中断」），侧栏/实例页状态一致。
8. **匿名 AI 节点**：agent 未指定的 AI 节点跑完 → `agents/` 下**不**新增文件；
   命名 agent 节点 → `agents/<name>.jsonl` 增量追加。
9. **同工作区隔离**：同一 worker 上两个工作区各建同名定义/实例互不可见
   （`workflow.def.list`/`instance.list` 按 workspace 过滤）。

## 7. hidden 工具（任务 AI 侧观察点）

1. 普通任务里问模型「帮我创建一个工作流定义…」→ 模型经 skill 文档调用
   `workflow_create/update/list/get/delete`；`plugin.list` RPC 可见 workflow 已启用。
2. 工具不进请求 tool 定义（前端/抓包看不到 schema），但模型按名调用成功——
   hidden 机制生效（应急回退：`worker.tools.hidden-enabled=false` 后工具转为常规暴露）。
3. **工作流自身 agent 不可见**：工作流 AI 节点里让模型尝试调用 workflow_create →
   不在 hidden 池（`appliesTo` 排除工作流主体），soft-fail 提示工具不存在。
